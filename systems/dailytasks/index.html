    Sistema de Daily Tasks

    Complete missões diárias para acumular pontos e trocar por recompensas exclusivas no NPC Walter!

    O que são Daily Tasks?

    Daily Tasks são as missões diárias do jogo. Todos os dias você pode selecionar uma missão para completar. As missões são sempre de matar monstros específicos e são sorteadas aleatoriamente para você.

    Importante

    As missões diárias só contam quando você está no modo desafio!

    Níveis de Dificuldade

    As Daily Tasks possuem 3 níveis de dificuldade, cada um com quantidade diferente de monstros e pontos de recompensa. Quanto maior o nível, mais monstros você precisa derrotar!

    Bronze

    3 pontos

    Menos monstros

    Prata

    7 pontos

    Quantidade média

    Ouro

    14 pontos

    Mais monstros

    Como Funcionam as Missões

    Todas as missões são de caçar monstros. Você escolhe uma missão dentre as disponíveis e precisa derrotar a quantidade indicada de monstros. Lembre-se: você só pode completar uma missão por dia e elas só contam no modo desafio!

    Limite diário

    Você só pode completar uma missão por dia. Escolha sabiamente qual dificuldade vale mais a pena para você!

    Sistema de Reroll

    Não gostou das missões disponíveis? Você pode fazer um reroll para sortear novas missões! O primeiro reroll é gratuito, e você tem mais 4 rerolls pagos com gold disponíveis.

    1º Reroll

    Gratuito para Premium ou AD para Free

    Rerolls extras

    4 disponíveis (pago com gold)

    Recompensas

    Os pontos acumulados podem ser trocados no NPC Walter! Ele oferece recompensas exclusivas que só podem ser obtidas com pontos de task. As missões também dão um pouco de XP, mas a quantidade é insignificante.

    Recompensas disponíveis no NPC Walter

    • • Chaves especiais
    • • Mochilas exclusivas
    • • Skin exclusiva disponível apenas por pontos de task

    Sobre o XP

    As missões também dão XP ao completar, porém a quantidade é insignificante. O foco principal são os pontos de task!

    Resumo Rápido

    Selecione uma missão por dia

    Escolha entre Bronze (3pts), Prata (7pts) ou Ouro (16pts)

    Mate os monstros indicados no modo desafio

    Use reroll se não gostar das missões (1 grátis + 4 pagos)

    Acumule pontos para trocar no NPC Walter

    Compre chaves, mochilas e uma skill exclusiva!
