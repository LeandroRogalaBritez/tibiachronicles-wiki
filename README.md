# Tibia Chronicles Wiki

Wiki feita por fãs, com conteúdo completo e gratuito sobre o jogo **Tibia Chronicles**: monstros, itens, spells, fases de caça, imbuements, sistemas do jogo e guias para jogadores novos e veteranos.

🔗 Site: [www.tibiachronicles.wiki](https://www.tibiachronicles.wiki)

## 📖 Sobre o projeto

O Tibia Chronicles Wiki centraliza informações do servidor/jogo Tibia Chronicles em um único lugar, cobrindo:

- **Monstros** — atributos, loot e localização
- **Itens** — descrições e onde encontrar
- **Spells** — magias disponíveis por vocação
- **Fases de caça** (hunting zones)
- **Imbuements**
- **Sistemas do jogo** — hazard, daily tasks, forja, guild, loyalty, boosted creature
- **Guias práticos** para todos os níveis

## 🛠️ Tecnologias

- **React** (SPA)
- **Vite** — build e bundling
- Hospedado via **GitHub Pages** em domínio customizado (`CNAME` → `www.tibiachronicles.wiki`)
- **Google Analytics (gtag.js)** para métricas de uso
- **Google AdSense** para monetização

## 🚀 Deploy

O site é servido via GitHub Pages, apontando para o domínio customizado configurado no arquivo `CNAME`.

## 📌 Status

Wiki em atualização contínua, acompanhando o desenvolvimento do jogo Tibia Chronicles.
